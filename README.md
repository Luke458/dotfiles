# Luke's dotfiles

Personal Arch/CachyOS, Hyprland, and Quickshell configuration managed with
[GNU Stow](https://www.gnu.org/software/stow/) and Git.

## Install

```sh
git clone git@github.com:Luke458/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh check
./install.sh install
```

`install.sh` targets `$HOME` by default. Set `STOW_TARGET` to validate or install
against another home directory. A subset can be managed by naming packages:

```sh
./install.sh install zsh git kitty nvim
./install.sh remove kitty
```

Two extra actions help with bring-up:

```sh
./install.sh doctor   # check tooling, Stow conflicts, and package-list drift
./install.sh deps     # install the recorded repo + AUR packages
```

Stow intentionally refuses to overwrite conflicting files. Back up an existing
configuration before installing. If adopting files from another machine, use
`stow --adopt` only after making a backup, then inspect `git diff` because the
target files become the repository copies.

## Packages

- Desktop shell: `hypr`, `quickshell`, `uwsm`, `desktop`, `theme`
- Terminal and shell: `zsh`, `kitty`, `git`
- Editors and file tools: `nvim`, `yazi`, `imv`
- Media and monitoring: `mpv`, `cava`, `btop`, `fastfetch`, `easyeffects`
- System integration: `systemd`, `containers`, `pinentry`, `helium`, `scripts`
- Package tooling: `pacman`, `paru`

The `packages/` directory records explicitly installed official-repository and
AUR/foreign packages. Refresh those lists with `packages/update.sh`.

Yazi plugins are not vendored. `yazi/.config/yazi/package.toml` pins each
plugin by revision and hash; restore them on a fresh machine with `ya pkg
install`.

`scripts/.local/bin/hermes` and `hermes-acp` are generated by `hermes update`.
That tool may replace the Stow symlink with a regular file, which makes the next
`install.sh check` report a conflict. Re-run `./install.sh install scripts`
after a Hermes update.

## Agent usage

The Quickshell bar's agent panel is ported from Omarchy's agents plugin. It
detects Claude Code, Codex, Grok, and Fireworks and shows limits, prepaid
balance, free rate-limit resets (Codex), and token history per subscription. The
five `omarchy-agent-usage-*` collectors under `scripts/.local/bin/` are vendored
from Omarchy; the `update` script finds them next to itself and writes one JSON
record per vendor to `~/.local/state/omarchy/agents/usage/`, which
`services/Agents.qml` watches.

Fireworks estimates a balance from `~/.config/omarchy/agents/fireworks.json`
(`fundedAmount`, optional `fundedAt`) unless a live ledger is available. Claude
limits need a signed-in `claude` CLI; Codex limits use the Codex app-server RPC;
Grok limits use the credits endpoint behind `grok usage`. A vendor with no data
does not appear in the bar.

Omarchy's multi-account management (`omarchy-agent-account-*`, per-account
switching) is not vendored; the collectors still read an account registry if one
exists, but this config manages a single account per vendor.

## Bar and desktop

- `quickshell/.config/quickshell/bar-widgets.json` controls the order, section
  (`primary` vs collapsible `expandable`) and visibility of every bar widget.
  Add a widget id to `hidden` to remove it without editing QML; a brand-new
  widget still needs a `Component` and a `componentForId()` entry in `Bar.qml`.
- Clipboard history: `scripts/.local/bin/clipboard-capture` is driven by
  `wl-paste --watch`, stored under `~/.local/state/quickshell/`, and opened with
  `SUPER+SHIFT+V`. Text and image entries are searchable; `Delete` removes one
  and `Ctrl+Delete` clears all (with a confirmation dialog).
- Display brightness uses DDC/CI (`ddcutil`) for the focused monitor and is
  bound to `XF86MonBrightnessUp`/`XF86MonBrightnessDown` with the on-screen
  display.
- The microphone bar widget toggles the default source mute
  (`XF86AudioMicMute`).

## Quadlets

The `containers` package tracks the five media-stack `.container` Quadlets and
their `.network` unit. The `systemd` package tracks `media-stack.target` and the
enabled user-unit links. Reload generated units after changing a Quadlet:

```sh
systemctl --user daemon-reload
systemctl --user restart media-stack.target
```

## Validation

`tools/check` runs the same checks locally and in CI
(`.github/workflows/ci.yml`): whitespace/conflict markers, `shellcheck` and
shell syntax, `luac -p`, `stylua --check` (only the Hypr and Neovim Lua trees),
a simulated Stow install, and a gitleaks secret scan. Checks whose tools are not
installed are skipped with a message.

Quickshell has its own runner at
`quickshell/.config/quickshell/tests/run-all.sh`. The lock, sleep, restart, and
service tests replace the real helpers with stubs and use an offscreen Qt
platform, so they are safe to run against a live session.

## Automatic synchronization

`dotfiles-sync.timer` checks every six hours, with a small randomized delay. It
safely fast-forwards a clean local checkout, refreshes the Arch package lists,
commits tracked changes, and pushes `main` when the remote is still an ancestor
of the local branch.

The sync deliberately refuses credential signatures (gitleaks, falling back to
ripgrep patterns), whitespace errors, a pre-staged index, remote divergence, and
remote updates that overlap local tracked changes. New untracked files are
reported in the journal but are never added or published automatically.

```sh
systemctl --user enable --now dotfiles-sync.timer
systemctl --user list-timers dotfiles-sync.timer
journalctl --user-unit dotfiles-sync.service
```

## Host-specific dependencies

Some configuration deliberately references this host's paths and services:

- Hyprland and Quickshell resolve `$HOME` at runtime; the Hermes, hypridle, and
  Attack Shark helpers keep absolute `/home/luke` paths because they are either
  generated by external tools or parsed by Hyprlang (which treats `$` as a
  variable).
- The `sbr` launcher and `services/SingBox.qml` expect the sing-box-routes
  project at `~/Projects/sing-box-routes`.
- `paru.conf` scans `/home/luke/Projects/pkgbuilds` for local PKGBUILDs.
- Media Quadlets expect `/home/luke/media-stack` and `/home/luke/data`.
- The Hermes wrappers and service expect `/home/luke/.hermes`.
- Helium's extension flag and native-messaging manifest point into
  `/home/luke/Projects/chromium-mpv`; neither format expands environment
  variables.
- The Quickshell pinentry executable is a generated build at
  `~/.local/bin/pinentry-quickshell`; its source is tracked, but the binary is not.
- Wallpaper files and application data are not tracked.

## Deliberate exclusions

Credentials and mutable application state are excluded even though the GitHub
repository is private. This includes SSH private keys, GitHub and Rclone auth,
password stores, browser profiles/cookies/history, Pulse cookies, caches, logs,
downloaded models, and generated build directories. Filenames are guarded by
`.gitignore`; file contents are scanned by `.gitleaks.toml` and the sync script.
